# SAEDscope

Identify the phase and zone axis in a selected-area electron diffraction (SAED) pattern. Upload a pattern or try a
simulated example in the sidebar. Physics does the matching (no training data); an optional language model only
explains the numbers.

Code, benchmark and details: see the project repository.
